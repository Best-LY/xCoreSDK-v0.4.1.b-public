# ✨ 距离自适应跟随 - 实现方案总结

## 🎯 功能需求

**原需求**：机械臂能够实现远离和靠近的动作，当标定板靠近时要后退，当标定板远离时要跟随

**实现状态**：✅ **已完成**

---

## 🔧 技术实现

### 新增3个核心功能

#### 1️⃣ 距离计算 `calcBoardDistance()`
```cpp
double calcBoardDistance(const Mat& tvec)
```
- **输入**：PnP解算的平移向量 tvec (相机坐标系)
- **计算**：$\sqrt{x^2 + y^2 + z^2}$ (欧几里得距离)
- **输出**：棋盘到相机的距离 (米)
- **调用频率**：每帧一次

#### 2️⃣ 距离修正 `adjustTargetByDistance()`
```cpp
void adjustTargetByDistance(Eigen::Isometry3d& target_pose, 
                           double current_distance, 
                           double target_distance)
```
- **输入**：目标位姿、当前距离、目标距离
- **逻辑**：
  - 如果 current_distance < target_distance → 后退（Z-方向）
  - 如果 current_distance > target_distance → 前进（Z+方向）
  - 在死区范围内不动作
- **输出**：修改后的目标位姿
- **调用频率**：每次PnP解算后

#### 3️⃣ 实时显示
```cpp
// 显示距离和状态
cv::putText(display, format("Dist: %.2fm (Target: %.2fm) - %s",
    board_distance, TARGET_FOLLOW_DISTANCE, distance_status.c_str()),
    Point(20, 100), ...);
```

## 🧮 距离计算示例

### 示例计算

假设PnP解算得到 tvec：
```
tvec = [-0.02]  (相机坐标系)
       [ 0.03]  (单位：米)
       [ 0.48]
```

距离计算：
```
distance = √((-0.02)² + 0.03² + 0.48²)
         = √(0.0004 + 0.0009 + 0.2304)
         = √0.2317
         ≈ 0.481m  (48.1cm)
```

### 调整计算

已知：
- current_distance = 0.481m
- target_distance = 0.50m
- DISTANCE_DEADZONE = 0.05m
- DISTANCE_SCALE = 0.5

计算过程：
```
distance_error = 0.50 - 0.481 = 0.019m (1.9cm)

是否在死区内？
|0.019| < 0.05 ✓ 是

结论：距离误差在死区内，不调整 (或调整为极小值)
状态：READY 🟢
```
