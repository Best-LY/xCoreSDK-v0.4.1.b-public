# 🚀 距离自适应跟随 - 快速开始指南

## 💡 核心概念

**机械臂与标定板保持恒定距离**：
- 📏 设置目标距离 (推荐 **50cm**)
- 🟢 距离正常 (48-52cm) → 保持不动
- 🟠 棋盘靠近 (< 48cm) → 机械臂后退
- 🔵 棋盘远离 (> 52cm) → 机械臂前进

## 🔧 常见问题速查

### Q: 显示 "SEARCHING TARGET" 不动

**A**: 
- [ ] 棋盘是否在相机视野内？
- [ ] 光照是否充足？
- [ ] 棋盘是否清晰？

### Q: 机械臂来回抖动

**A**: 减小补偿系数
```cpp
const double DISTANCE_SCALE = 0.3;  // 从0.5改到0.3
```

### Q: 响应太慢

**A**: 增加补偿系数和减小死区
```cpp
const double DISTANCE_SCALE = 0.7;  // 从0.5改到0.7
const double DISTANCE_DEADZONE = 0.03;  // 从0.05改到0.03
```

### Q: 距离精度不足

**A**: 
```cpp
const double DISTANCE_DEADZONE = 0.02;  // 减小
const double DISTANCE_SCALE = 0.8;      // 增大
```

## 🎓 工作原理速览

```
PnP解算得到 tvec (相机坐标)
    ↓
计算距离 = √(x² + y² + z²)
    ↓
距离误差 = 目标距离 - 当前距离
    ↓
if |误差| < 死区:
    不调整 (READY 🟢)
else if 误差 > 0:
    后退 (BACKING 🟠) ← 棋盘靠近
else:
    前进 (FORWARD 🔵) ← 棋盘远离
    ↓
调整目标位姿的Z轴
    ↓
平滑滤波 → 发送给机械臂
```
