## README: Rokae 双臂交互式拖拽手眼标定系统

### 📋 项目概述

本项目实现了一个基于 Rokae xMate 机械臂、Intel RealSense 深度相机和 OpenCV 库的**交互式手眼标定系统 (Hand-Eye Calibration)**。

程序允许用户通过**拖拽示教**的方式引导机械臂，实时采集机械臂末端位姿和标定板视觉位姿，并通过 Tsai 方法计算相机相对于机械臂法兰盘的变换矩阵 $H_{Flange \to Cam}$。

**核心功能：**

  * **稳定相机流：** 使用 RealSense SDK 连接相机，自动选择最稳定的分辨率（适用于虚拟机环境）。
  * **拖拽示教：** 利用 Rokae SDK 的 `enableDrag` 功能，在笛卡尔空间开启自由拖拽模式。
  * **数据同步采集：** 通过键盘输入同步采集机械臂位姿和视觉位姿。
  * **矩阵求解：** 使用 OpenCV 的 `calibrateHandEye` (Tsai 方法) 计算手眼矩阵。

### 🔨 构建步骤

假设您的 Rokae xCoreSDK 位于 `/home/best/xCoreSDK-v0.4.1.b`，并且已经配置了 CMakeLists.txt 以链接必要的库（如 `rokae`, `opencv`, `realsense2`）。

1.  **进入构建目录并执行 CMake：**
    ```bash
    cd /home/best/xCoreSDK-v0.4.1.b
    mkdir build
    cd build
    cmake ..
    ```
2.  **执行编译：**
    ```bash
    make -j$(nproc)
    # 或
    /usr/bin/cmake --build . --config Release --target all -j 8
    ```
3.  **运行程序：**
    ```bash
    ./example/tuozhuai-biaoding # 假设可执行文件名为 tuozhuai-biaoding
    ```

### 📝 配置说明 (User Configuration)

在 `tuozhuai-biaoding.cpp` 文件头部，您必须根据您的实际硬件修改以下配置：

| 参数 | 类型 | 描述 |
| :--- | :--- | :--- |
| `IP_LEFT` | `string` | **左臂**机械臂控制器的 IP 地址。 |
| `IP_RIGHT` | `string` | **右臂**机械臂控制器的 IP 地址。 |
| `SN_LEFT_CAM` | `string` | **左臂**相机的唯一序列号 (Serial Number)。 |
| `SN_RIGHT_CAM` | `string` | **右臂**相机的唯一序列号 (Serial Number)。 |
| `BOARD_SIZE` | `Size` | 标定板内角点数量 `(宽, 高)`，例如 `(9, 6)`。 |
| `SQUARE_SIZE` | `float` | 标定板每个方格的边长，单位为**米**。 |

> **⚠️ 注意：** 相机序列号 **不能随意填写**。请使用 `rs-enumerate-devices` 或 RealSense Viewer 工具查询您已连接的相机序列号。

### 🚀 操作指南

1.  **启动程序：** 运行编译后的可执行文件。
2.  **选择机械臂：** 程序将提示您选择标定左臂还是右臂（输入 1 或 2）。
3.  **进入拖拽模式：** 机械臂连接成功后将自动开启拖拽模式，并启动相机和图像窗口。
4.  **拖拽示教：** 用手拖动机械臂，使相机能够清晰地看到标定板。
5.  **采集数据点：**
      * 确保图像窗口上显示 **"READY TO CAPTURE"**。
      * 按下键盘上的 **【空格键】** (Spacebar) 采集当前点位。
      * **重要：** 改变机械臂的**位置和姿态**（即旋转手腕），重复此过程至少采集 **15 个** 有足够多样性的点。
6.  **完成计算：** 采集足够的点后，按下 **【Q】** 或 **【ESC】** 退出采集循环。
7.  **结果输出：** 程序将计算手眼矩阵 $H_{Flange \to Cam}$，并在控制台输出，同时保存到名为 `LeftArm_interactive_calib.yml` 或 `RightArm_interactive_calib.yml` 的文件中。

### 🔍 关键代码调整 (供参考)

| 关键调整点 | 目的 |
| :--- | :--- |
| `enableDrag`, `disableDrag` | 适配您 SDK 版本中正确的拖拽函数名称。 |
| `error_code ec;` | 解决 C++ 中非 `const` 左值引用不能绑定临时对象 (右值) 的编译错误。 |
| `cfg.enable_stream(RS2_STREAM_COLOR, RS2_FORMAT_BGR8);` | 不指定分辨率，让 RealSense 自动选择稳定配置，以确保虚拟机下启动成功。 |
| `Mat frame(Size(cam_width, cam_height), CV_8UC3, ...)` | 动态读取相机实际分辨率，确保 OpenCV 图像尺寸与相机输出匹配。 |
